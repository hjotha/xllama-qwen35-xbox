## 2. Blocker found during the full-suite regression (cause)

Symptom: full suite with XLLAMA_TEST_MODEL set never finished (timeout 600,
then timeout 420, EXIT=124); the tail stopped after an mtp generate (n=8,
37 tok) plus MTP_STATS, with 0 fault-probe markers.

Localization (single-test focal + temporary cooperative stderr markers,
reverted afterwards): stall inside tests/test_sampling.cpp
"mtp: chunked prefill keeps parity and keeps drafting", at
CHECK(r_whole.mtp_active) — markers stop after the post-generate REQUIRE,
and the reporter's "logged:" line never prints.

Root cause: the INFO declared before the first generate re-evaluates its
stream expression lazily when a LATER assertion fails, including
((n_prompt + sp.n_batch - 1) / sp.n_batch); the test sets sp.n_batch = 0
before the whole-prefill leg, so failure reporting divides by zero. The
SIGFPE fires inside doctest's ConsoleReporter while it already holds its
own non-recursive mutex (log_assert), and reportFatal's test_case_exception
re-locks the same mutex: self-deadlock. Observed state: every thread parked
in futex_do_wait with frozen utime; the process stays alive until killed.
Reproduced in isolation with a pure-doctest case (temporary, reverted).

Not the probe: the chunked test never calls save_state (0 probe markers in
every hung log). The fixture stories15M-q4_0.gguf carries no MTP head (the
tests require it), so mtp_active=false is a legitimate failure — the defect
was only the lazy division turning the failure report into a hang.

Fix (tests/test_sampling.cpp only): eager snapshot of n_batch and the chunks
quotient at INFO declaration; INFO text, every CHECK/REQUIRE, and every
numeric limit unchanged.
clang-format 22.1.5 --dry-run --Werror on the file: FORMAT_OK.
